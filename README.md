Damped long-window log-linear trend forecast of Bitcoin's price 4 hours ahead: the ordinary-least-squares slope of log(price) over the last 48 hours of 1-minute closes, extrapolated 240 minutes and damped by 0.7, anchored on the checkpoint close. Backtest MAE 42,833.95 cents over practice cases p00..p04 (persistence: 47,054.66 cents). Runs offline with the Node 22 standard library only; no network, deterministic.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
